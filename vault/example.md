#Biology #Notes

Mitochondria:: Organelle responsible for ATP production.
Ribosome:: Structure responsible for protein synthesis.
Nucleus:: Compartment that stores most of a cell's genetic information.
Lysosome:: Organelle that breaks down cellular waste.

#Python #Notes

**Term:** Function
**Definition:** A reusable block of code that performs a task.

```python
def add(a, b):
    return a + b

print(add(5, 4))
```
